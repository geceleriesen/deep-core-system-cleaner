# ⚡ Deep Core System Diagnostics Pro

A standalone, full-stack Windows system diagnostics & real-time monitoring tool built with **Python (Flask & psutil)** and a modern **Glassmorphism UI**.

## 🌟 Key Features

- ⚡ **Realtime Telemetry Engine:** Zero-latency background thread monitoring for accurate CPU usage, RAM utilization, and active network interfaces.
- 📡 **Network Intel HUD Pro:** Picture-in-Picture (PIP) floating window with live bandwidth charts (Sparklines), Cloudflare ping latency tests, and active socket inspection.
- 🛡️ **Multi-Tier Safety Guard:** Automatic process classification (`LOW`, `MEDIUM`, `HIGH RISK`) preventing accidental termination of critical Windows system infrastructure.
- 🧹 **Fast RAM Boost:** One-click memory optimization that safely terminates non-pinned high-memory background applications.
- 📌 **Custom App Pinning (Whitelist):** Pin your favorite productivity tools (Discord, Spotify, VS Code) to insulate them from memory cleanups.
- 📋 **Audit History Panel:** Real-time session logging for all process management operations.
